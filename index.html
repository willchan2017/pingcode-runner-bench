克隆链路一次跨实例克隆要过的六道关
① 发起
工作项详情「更多操作 → 跨实例 Clone」，入口由项目范围 + 角色共同决定。
›
② 三层映射
字段 → 值（枚举） → 用户，映射缺失则在发起前拦截。
›
③ 前置校验
目标实例必填字段、枚举合法性、附件大小、用户映射完整性。
›
④ 专线传输
走内网专线，数据不出公网；失败按指数退避重试 3 次。
›
⑤ 对方审核
接收方审核人审批通过后才落库；驳回则回写失败原因。
›
⑥ 回写关联
副本 ID / 链接写回源单 remote link，双方关键属性按策略联动。
实例连接跨实例克隆的网络与认证前提；只有已连接的实例才能作为目标
实例名称地址网络认证方式方向状态最近心跳操作

NPU 张量计算核在 INT8 量化下累加精度偏差超规格
负责人
王王若上
状态
问题处理中
开始时间
-
结束时间
-
「关闭问题」挂了关联对象条件：入口照常展示，点击时校验；「挂起」按角色条件（仅子系统负责人）对当前用户不展示。
描述
在 INT8 量化模式下跑通算子基准（MobileNet / ResNet50）时，张量计算核的累加结果相较参考模型偏差达到 0.031，规格要求 ≤ 0.008，偏差约 3.9 倍。在 FP16 模式下偏差为 0.004，满足规格。初步定位与累加器位宽截断配置及 INT8 反量化时序有关。
发现步骤
1. 使用 NPU 算子回归集连续跑 INT8 量化基准 200 次
2. 约 8% 轮次偏差超规格，偏差值随批量大小波动
3. 定位到 mac_int8_accum 模块的反量化流水拍配置与规格文档不一致
